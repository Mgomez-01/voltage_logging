# Libraries used by the ESP8266 Voltage + Temperature Logger

PlatformIO installs everything automatically from platformio.ini.
This list is for reference or for a manual Arduino IDE / Arduino CLI build.

## From the ESP8266 Arduino core (no separate install)
- ESP8266WiFi        - WiFi access point
- ESP8266WebServer   - HTTP server (port 80)
- SD + SPI           - microSD card log files
- LittleFS           - internal flash; holds only the web page template
- Ticker             - timer-based safety checks and watchdog

## External libraries
1. ArduinoJson by Benoit Blanchon
   - Version 7.x (platformio.ini: ArduinoJson@^7.0.0)
   - The code uses the v7 JsonDocument API, so 6.x will not compile
2. WebSockets by Markus Sattler (links2004)
   - Version 2.4.x or newer (platformio.ini: WebSockets@^2.4.0)
   - Provides WebSocketsServer (port 81)

## ESP8266 board package (Arduino IDE only)
- Board Manager URL: http://arduino.esp8266.com/stable/package_esp8266com_index.json
- Install "esp8266" by ESP8266 Community
- Board: NodeMCU 1.0 (ESP-12E Module) or LOLIN(WEMOS) D1 mini

## Notes for Arduino IDE users
- The firmware is split across several files in src/ (main.cpp plus modules),
  so copy the whole src/ folder into the sketch folder
- The web page (data/index.template.html) must also be uploaded to LittleFS
  with the LittleFS upload tool
