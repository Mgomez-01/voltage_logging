Program

One step per line: a setpoint in °C, optionally followed by its own hold time in minutes (62.5, 62.5 15, 62.5, 15 or 62.5:15). Up to 40 steps. Each step holds for its time from when it starts, without waiting for the temperature to settle. Setpoints apply to the selected control sensor (-, set on the main page).

Generate a list

Uses the default hold for every step. Replaces the list above.

Start turns on logging (to the current log file, with the main page's averaging setting) and the PID, then runs the steps on the board: the page can be closed. Logging, heater or PID changes on the main page stop the program.
